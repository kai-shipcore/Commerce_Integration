④ Search, Filters, and CSV Export

Use the top toolbar to find SKUs quickly and save the current result set for review or bulk maintenance.

FeatureHow to use itWhat to know
SKU SearchEnter any part of a Master SKU. The list refreshes automatically after a short delay.Reset clears the search and returns to page 1.
Product, Status, TypeCombine product group, active status, and sales type filters to narrow the list.The default status is Active. Select All Status or Inactive when a retired SKU is missing.
Download CSVExports all rows matching the current search and filters, not only the visible page.The file contains product, Master SKU, product name, category, status, CBM, MOQ, order multiple, case quantity, and weight.
💡
Can the export be imported again? Yes. It contains the Master SKU, CBM, MOQ, and Order Multiple columns recognized by Excel Import. Extra columns are ignored. Sales Type is not currently included in the CSV export.

⑤ Sync Inventory — Refresh the SKU List

Sync Inventory reads Master SKUs from ecommerce_data.coverland_inventory_by_warehouse and adds or updates records in shipcore.fc_products. SKU Master edit permission is required.

1

Start the sync

Make sure no one is in the middle of a bulk edit, then click Sync Inventory.

2

Collect and normalize SKUs

Blank and duplicate SKUs are removed, SKU formatting is normalized, and defaults for new SKUs are inferred from their SKU pattern.

3

Insert or refresh

Missing SKUs are inserted. Existing rows have blank product/category details filled in and are set to Active.

4

Review the result

Check the synchronized count in the completion message. The list reloads automatically.

DataSync behavior
New SKUInserted as Active with inferred product group, CBM, MOQ, order multiple, case quantity, and weight defaults.
Existing CBM/MOQ/MultiplePreserved. Inventory sync does not overwrite maintained planning values.
Existing Sales TypePreserved. Sales Type is not supplied by the inventory source.
Existing StatusSet to Active when the SKU still exists in the external inventory list.
SKU absent from sourceNot automatically deleted or deactivated; the existing SKU Master row remains.
⚠️
Inactive SKU warning: An inactive SKU that still exists in the inventory source can become active again after synchronization. Review All Status after the sync.

⑥ Excel/CSV Import — Update Reference Values in Bulk

Excel Import adds or updates CBM, MOQ, and Order Multiple for many SKUs. It accepts .xlsx, .xls, and .csv files and requires SKU Master edit permission.

1

Prepare a template

Download the template or prepare headers in an existing file. Master SKU is required, with at least one valid CBM, MOQ, or Order Multiple value.

2

Choose a file

Select the Excel or CSV file. Master SKUs are uppercased and normalized to the internal SKU format.

3

Review the preview

Check the New, Updated, and Unchanged counts and each field's current → new value. Nothing has been written yet.

4

Confirm and apply

Click Confirm & Apply. Unchanged rows are skipped, and the final inserted/updated counts are shown.

ColumnValidationBlank cell behavior
Master SKURequired; use a SKU containing a hyphen (-).The row is skipped.
CBMA number greater than zero. The first number can be read from cells containing commas or units.The current value is retained for an existing SKU.
MOQAn integer of at least 1.The current value is retained for an existing SKU.
Order MultipleAn integer of at least 1.The current value is retained for an existing SKU.
🧾
When importing a new SKU: Missing reference values are filled with defaults inferred from the SKU pattern. Product details, case quantity, and weight are also created. Always verify the preview's final values.
⚠️
Duplicates and multiple sheets: Only one row is used for a duplicate SKU. With duplicate SKUs across sheets, sheet priority and CBM precision may determine which row wins. For critical imports, keep one row per SKU in a single template sheet.

⑦ Price History — Review Factory-specific Effective Prices

Click Price or click a row while it is not being edited to open the right-side drawer. The feature is visible only to users with Invoice Price Control read permission.

AreaHow it works
FactorySelect a factory to load history for that SKU and factory. Use Refresh to reload the latest records.
Current PriceThe drawer header shows the price with the latest effective date in the selected factory history.
Change HistoryShows effective date, unit price, change amount, and change rate. Click the Effective header to reverse the sort.
Lookup by DateSelect a date to find the latest price whose effective date is on or before it. Invoice validation uses the same rule for Invoice Date.
Add/EditWith permission, enter effective date, USD unit price, and reason. Use the pencil action to edit an existing row.
DeleteThe trash action appears only with delete permission and removes the row after confirmation.
💡
No Price button? Ask an administrator to check Invoice Price Control → Read. Create, edit, and delete actions are also shown independently according to permission.

⑧ Troubleshooting

SymptomWhat to check
A SKU is missingChange the default Active filter to All Status, then clear search, product, and sales type filters.
Import preview is emptyConfirm a Master SKU header, a hyphenated SKU, and at least one valid CBM, MOQ, or Order Multiple value.
Some file values were ignoredBlank cells preserve current values. CBM must be positive; MOQ and Order Multiple must be integers of at least 1.
Inventory sync failsCheck SKU Master edit permission and the lookup database configuration. Send the message shown at the bottom of the screen to an administrator.
An edited value revertedThe row returns to its previous values when saving fails. Check permissions and values, then save again.
