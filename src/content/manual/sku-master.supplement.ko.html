④ 검색·필터·CSV 다운로드

상단 도구 모음은 원하는 SKU를 빠르게 찾고, 현재 조회 조건에 맞는 목록을 파일로 보관할 때 사용합니다.

기능사용 방법알아둘 점
SKU 검색 Master SKU의 일부를 입력합니다. 입력 후 약간의 대기 시간을 두고 자동으로 다시 조회됩니다. 초기화를 누르면 검색어가 지워지고 첫 페이지로 돌아갑니다.
제품·상태·판매 유형 제품군(Car Cover, Floor Mat, Seat Cover, Accessories), 활성 상태, 판매 유형을 조합해 범위를 좁힙니다. 기본 상태 필터는 활성입니다. 비활성 SKU가 보이지 않으면 전체 상태 또는 비활성을 선택하세요.
CSV 다운로드 현재 검색어와 제품·상태·판매 유형 필터에 맞는 전체 결과를 CSV로 저장합니다. 화면에 보이는 한 페이지만 저장하는 기능이 아닙니다. 파일명은 sku-master-YYYY-MM-DD.csv입니다. 제품, Master SKU, 제품명, 카테고리, 상태, CBM, MOQ, 주문 배수, Case Qty, 중량이 포함됩니다.
💡
CSV를 다시 가져올 수 있나요? 다운로드한 CSV에는 엑셀 가져오기가 인식하는 Master SKU, CBM, MOQ, Order Multiple 열이 포함되어 있으므로 값을 수정한 뒤 다시 가져올 수 있습니다. 그 밖의 열은 가져오기에서 무시되며, 판매 유형은 현재 CSV 다운로드 대상이 아닙니다.

⑤ 재고 동기화 — SKU 목록을 최신 상태로 맞추기

재고 동기화는 외부 재고 DB의 ecommerce_data.coverland_inventory_by_warehouse에서 Master SKU 목록을 읽어 SKU 마스터(shipcore.fc_products)에 추가하거나 기존 행을 정리합니다. SKU 기준 정보 편집 권한이 있는 사용자만 실행할 수 있습니다.

1

실행 전 필수 값 확인

대량 수정 중인 사용자가 없는지 확인하고 재고 동기화를 누릅니다. 동기화 중에는 버튼이 동기화 중...으로 바뀝니다.

2

외부 재고 SKU 수집·정규화

빈 SKU를 제외하고 중복을 제거합니다. SKU 표기를 내부 규칙에 맞게 정규화한 뒤 제품군과 신규 SKU의 기본 기준값을 추론합니다.

3

신규 추가 또는 기존 갱신

없는 SKU는 새로 추가합니다. 기존 SKU는 비어 있는 제품명·카테고리 정보를 보완하고 상태를 활성으로 맞춥니다.

4

결과 확인

완료 메시지의 동기화 건수를 확인합니다. 목록은 자동으로 다시 조회됩니다. 필요한 SKU를 검색해 CBM·MOQ·판매 유형을 점검하세요.

항목동기화 시 처리
신규 SKUSKU 패턴을 기준으로 제품군, CBM, MOQ, 주문 배수, Case Qty, 중량의 기본값을 만들어 활성 상태로 추가합니다.
기존 CBM·MOQ·주문 배수유지됩니다. 사용자가 입력한 기준값을 재고 동기화가 덮어쓰지 않습니다.
기존 판매 유형유지됩니다. 외부 재고 DB에서 판매 유형을 가져오지 않습니다.
기존 상태외부 재고 목록에 존재하면 활성으로 갱신됩니다.
외부 목록에서 사라진 SKU자동 삭제하거나 비활성화하지 않습니다. 기존 SKU 마스터 행이 그대로 남습니다.
⚠️
비활성 SKU 주의: 외부 재고 목록에 남아 있는 비활성 SKU는 재고 동기화 후 다시 활성화될 수 있습니다. 동기화가 끝난 뒤 상태 = 전체 상태로 필터하여 의도한 상태인지 확인하세요.

⑥ 엑셀/CSV 가져오기 — 기준값 일괄 반영

엑셀 가져오기는 여러 SKU의 CBM, MOQ, 주문 배수를 한 번에 추가·수정하는 기능입니다. .xlsx, .xls, .csv 파일을 지원하며, SKU 기준 정보 편집 권한이 필요합니다.

1

템플릿 준비

가져오기 창에서 템플릿 다운로드를 누르거나 기존 파일의 헤더를 준비합니다. Master SKU는 필수이며 CBM, MOQ, Order Multiple 중 하나 이상에 유효한 값이 있어야 합니다.

2

파일 선택

엑셀 / CSV 파일 선택을 눌러 파일을 엽니다. Master SKU는 대문자로 정리되며 내부 SKU 정규화 규칙이 적용됩니다.

3

변경 미리보기 검토

신규 추가·기존 수정·변경 없음 건수와 각 필드의 기존값 → 새 값을 확인합니다. 이 단계에서는 아직 DB에 반영되지 않습니다.

4

확인 후 적용

내용이 맞으면 확인 후 적용을 누릅니다. 변경 없는 행은 제외되고, 적용 완료 후 수정·추가 건수가 표시됩니다.

열입력 규칙빈 셀 처리
Master SKU필수. 하이픈(-)이 포함된 SKU를 사용합니다.행 전체를 건너뜁니다.
CBM0보다 큰 숫자. 쉼표나 단위가 포함된 셀도 첫 번째 숫자를 읽습니다.기존 SKU는 현재 값을 유지합니다.
MOQ1 이상의 정수.기존 SKU는 현재 값을 유지합니다.
Order Multiple1 이상의 정수.기존 SKU는 현재 값을 유지합니다.
🧾
새 SKU를 가져올 때: 파일에 없는 기준값은 SKU 패턴으로 추론한 기본값으로 채워지며, 제품명·제품군·Case Qty·중량도 함께 생성됩니다. 미리보기에서 세 필드의 최종값을 반드시 확인하세요.
⚠️
중복 SKU와 여러 시트: 같은 SKU가 여러 번 있으면 한 행만 사용합니다. 여러 시트에 동일 SKU가 있으면 시스템의 시트 우선순위와 CBM 소수점 정밀도에 따라 선택될 수 있으므로, 중요한 일괄 작업은 템플릿의 한 시트에 SKU당 한 행만 두는 것이 가장 안전합니다.

⑦ 가격 이력 — 공장별 적용 단가 확인

행의 가격 이력 버튼 또는 편집 중이 아닌 행을 클릭하면 오른쪽 패널이 열립니다. 이 기능은 Invoice Price Control 조회 권한이 있는 사용자에게만 표시됩니다.

영역사용 방법
공장 선택상단 공장 목록에서 공장을 선택하면 해당 SKU·공장의 가격 이력만 조회합니다. 새로고침 버튼으로 최신 데이터를 다시 불러올 수 있습니다.
현재가패널 제목의 현재가는 선택한 공장 이력 중 적용 시작일이 가장 최근인 가격입니다.
가격 변경 이력적용 시작일, 단가, 이전 가격 대비 변동액·변동률을 보여줍니다. 적용일 제목을 누르면 오름차순/내림차순을 전환합니다.
특정 날짜 가격 조회날짜를 선택하면 그 날짜 이하의 적용일 중 가장 최근 가격을 찾습니다. Invoice 검수도 같은 방식으로 Invoice Date에 적용되는 가격을 선택합니다.
가격 추가·수정권한이 있으면 적용 시작일, 단가(USD), 변경 사유를 입력해 저장합니다. 기존 이력의 연필 버튼을 누르면 수정 모드로 전환됩니다.
가격 삭제삭제 권한이 있는 경우에만 휴지통 버튼이 표시됩니다. 확인 창에서 승인하면 해당 이력이 삭제됩니다.
💡
가격 버튼이 보이지 않을 때: 오류가 아니라 권한 설정 때문일 수 있습니다. 관리자에게 Invoice Price Control → 조회 권한을 확인해 달라고 요청하세요. 추가·수정·삭제 버튼도 각각의 권한에 따라 따로 표시됩니다.

⑧ 자주 묻는 문제

증상확인할 내용
찾는 SKU가 보이지 않음기본 상태가 활성인지 확인하고 전체 상태로 바꿔 보세요. 검색어와 제품·판매 유형 필터도 초기화합니다.
가져오기 미리보기가 비어 있음헤더에 Master SKU가 있는지, SKU에 하이픈이 있는지, CBM/MOQ/Order Multiple 중 유효한 값이 하나 이상 있는지 확인합니다.
파일 값 일부가 반영되지 않음빈 셀은 기존 값을 유지합니다. CBM은 0보다 커야 하고 MOQ·주문 배수는 1 이상의 정수여야 합니다.
재고 동기화 실패SKU 기준 정보 편집 권한과 외부 조회 DB 연결 설정을 확인합니다. 계속 실패하면 화면 하단 오류 메시지를 관리자에게 전달하세요.
편집 후 값이 원래대로 돌아옴저장 실패 시 화면은 편집 전 값으로 복원됩니다. 권한과 입력값을 확인한 뒤 다시 저장하세요.
