발주 목록 (Action List)

예측, 가용 재고, 선주문 잔량과 확정 입고를 한곳에서 비교해 지금 확인해야 할 SKU와 권장 발주량을 찾는 화면입니다.

💡
이 화면의 목적: 모든 SKU를 단순 나열하는 것이 아니라, 재고 위험과 수요를 기준으로 검토 순서를 만들어 줍니다. 권장 발주량은 자동 발주나 확정 주문이 아니라 담당자가 검토할 시작값입니다.

가장 쉬운 사용 순서

1

데이터와 모델 기준 확인

상단의 학습 기준, 모델, 예측 범위와 Forecast Server 상태를 먼저 확인합니다. 오래된 예측이면 예측 다시 실행을 열어 갱신합니다.

2

계획 조건 설정

리드타임, 발주 주기, 서비스 수준, 품절 위험 기간을 현재 조달 조건에 맞춥니다. 값을 바꾸면 서버가 조건에 맞춰 목록과 권장 수량을 다시 계산합니다.

3

업무 목적에 맞는 카드 선택

선주문, 보유 재고 없음, 주력 상품, N일 내 품절, 입고 전 품절, 초안 발주 있음, 일반 중 하나를 눌러 목록을 좁힙니다. 선택한 카드를 다시 누르면 전체로 돌아갑니다.

4

표와 상세 근거 확인

발주 수량만 보지 말고 가용 재고, 입고 예정, 품절 시점과 신뢰도를 함께 봅니다. SKU를 누르면 계산식, 판매·예측 그래프와 백테스트 근거를 확인할 수 있습니다.

5

업무 목록으로 내보내기

필요한 필터와 정렬을 적용한 뒤 CSV 내보내기를 누릅니다. CSV에는 현재 필터에 남은 전체 행이 포함됩니다.

화면 상단 정보

항목의미와 확인 방법
학습 기준예측 모델이 실제 판매 데이터를 학습한 마지막 기준일입니다. 오늘 날짜와 다를 수 있으므로 발주 판단 전에 확인합니다.
모델현재 목록을 만든 모델 버전입니다. 버전을 누르면 모델의 목적과 주요 특성을 화면을 떠나지 않고 확인할 수 있습니다.
예측 범위현재 예측이 도달하는 마지막 날짜입니다. 계획 조건의 커버 기간보다 충분히 멀리 예측되어 있는지 확인합니다.
Forecast Server예측 서비스 연결 상태입니다. 연결 실패 시 계획 조건 변경, 목록 조회 또는 상세 조회가 실패할 수 있습니다.
예측 SKU현재 예측 결과가 있고, 최신 분류에서도 예측 대상으로 유지된 SKU 수입니다.
비정기로 재분류되어 제외예측 실행 뒤 판매 패턴이 비정기형으로 바뀌어 현재 목록에서 빠진 SKU 수입니다. 다음 예측 실행 때 예측 대상에서도 제외될 수 있습니다.
샘플 재고 데이터이 문구가 보이면 화면의 재고 수치는 실제 운영 재고가 아닙니다. 실제 발주 판단에 사용하면 안 됩니다.

예측 다시 실행

학습 기준이 오래되었거나 최신 주문을 반영해야 할 때 접힌 예측 다시 실행 영역을 엽니다.

항목사용 방법
예측 기간13주, 26주, 52주 중 선택합니다. 기간이 길수록 더 먼 미래까지 예측 결과를 만듭니다.
실행 단계동기화 → 수집 → 분류 → 예측의 4단계로 진행됩니다. 동기화는 보통 몇 분 걸릴 수 있습니다.
갱신 화면완료되면 Action List와 예측 검증 화면이 갱신됩니다. SKU 플래닝은 주간 자동 실행 결과를 계속 사용합니다.
중단 불가실행 중에는 판매 데이터·분류·예측 파일의 기준 주가 어긋나는 것을 막기 위해 이 화면에서 중단할 수 없습니다. 브라우저를 반복 조작하지 말고 완료될 때까지 기다립니다.
실패·외부 중단실패하면 이전 예측이 유지됩니다. 외부에서 중단되었다는 경고가 나오면 세 데이터가 서로 다른 주를 가리킬 수 있으므로 다시 실행해 끝까지 완료합니다.
실행 로그단계별 수량이나 경고가 필요하면 완료 또는 실패 후 로그를 펼쳐 확인합니다.

예측 대상과 예측 제외

예측 대상

주간 수요 예측이 있는 SKU입니다. 예측 수요와 오차, 재고, 선주문, 입고를 사용해 품절 시점과 권장 발주량을 계산합니다.

예측 제외

판매가 너무 불규칙해 주간 예측 대상이 아닌 SKU입니다. 최근 13주 실제 판매로 재고 여유만 보여주며, 모델 기반 권장 발주량과 신뢰도는 만들지 않습니다.

예측 대상 요약 카드

카드는 현황 숫자인 동시에 필터입니다. 같은 업무 목적의 SKU만 빠르게 남길 수 있습니다.

카드무엇을 보여주나요?
전체현재 예측 가능한 전체 SKU입니다. 다른 카드를 선택한 뒤 전체로 돌아갈 때 누릅니다.
선주문선주문 잔량 때문에 우선 확인해야 하는 SKU입니다.
보유 재고 없음현재 가용 재고가 0 이하인 모든 SKU입니다. 행의 No Stock 우선순위와는 범위가 다를 수 있습니다. 예를 들어 재고가 없고 선주문도 있으면 행 배지는 Preorder이지만 이 카드에는 포함됩니다.
주력 상품최근 4주 판매량을 큰 순서로 누적했을 때 전체 수요의 절반을 차지하는 소수 SKU입니다. 재고 위험이 아니라 상품의 중요도를 나타내므로 Preorder, No Stock, Routine 어느 행에도 별표가 붙을 수 있습니다.
N일 내 품절설정한 품절 위험 기간 안에 현재 재고가 소진될 것으로 계산된 SKU입니다.
입고 전 품절확정 입고가 있지만 그 입고가 도착하기 전에 재고가 먼저 소진되는 SKU입니다. 추가 발주보다 기존 입고 앞당김이나 재고 재배분이 더 빠른 해결책일 수 있습니다.
초안 발주 있음아직 확정되지 않은 컨테이너 초안에 수량이 잡힌 SKU입니다. 이미 검토한 항목을 따로 확인할 때 사용합니다. 초안 수량은 확정 입고가 아니므로 권장 발주량에서 차감되지 않습니다.
일반선주문도 없고 판매 가능한 재고도 있어 평상시 발주 주기로 검토하는 Routine SKU입니다.
권장 수량현재 화면에 남은 SKU의 권장 발주량 합계입니다. 필터가 적용되면 권장 수량 · 현재 목록으로 표시되고, 아래에 필터 전 전체 합계가 함께 표시됩니다.

🔗
상세 화면과 조건이 이어집니다. SKU 행을 열면 현재 목록의 계획 조건이 URL에 함께 전달됩니다. 따라서 목록과 상세의 권장 수량을 같은 조건으로 비교할 수 있고, 링크를 공유해도 같은 조건이 재현됩니다.

필터, 열 선택, 정렬과 내보내기

  • 검색: SKU 코드 또는 상품명 일부를 입력합니다.
  • 카테고리: 선택한 상품 카테고리만 남깁니다.
  • 신뢰도: 좋음, 보통, 낮음, 미측정으로 좁힙니다.
  • 수요 추세: 상승, 보합, 하락, 급감, 알 수 없음으로 좁힙니다. 최근 4주 판매를 계절성을 제거한 최근 12주 평균과 비교한 결과입니다.
  • 데이터 품질 경고: 경고가 있는 SKU 수와 경고 종류가 표 위에 나타납니다. 전체 경고 문구나 개별 경고명을 누르면 해당 SKU만 남고, 같은 항목을 다시 누르면 해제됩니다.
  • 표시 개수: 25, 50, 100, 200개 또는 전체 보기를 선택합니다. 표 내부는 상하·좌우로 스크롤할 수 있으며 SKU 열과 머리글은 고정됩니다.
  • 열: 재고 현황, 수요, 조치 그룹별로 필요한 열만 표시합니다. 개별 열을 선택하거나 그룹 전체를 숨기고 다시 보일 수 있습니다. SKU와 우선순위는 항상 표시되며, 최소 한 개의 선택 열은 남아야 합니다.
  • 열 설정 저장: 선택한 열은 현재 브라우저에 자동 저장되어 다음 방문에도 유지됩니다. 버튼에 ‘N개 숨김’이 보이면 이전에 숨긴 열이 있다는 뜻입니다. 모든 열 보기로 되돌릴 수 있습니다.
  • 정렬: 열 제목을 클릭하면 정렬됩니다. 같은 열을 다시 누르면 방향이 바뀌고, 한 번 더 누르면 기본 업무 우선순위 순서로 돌아갑니다. Shift를 누른 채 다른 열을 클릭하면 다중 정렬이 됩니다.
  • 초기화: 요약 카드, 검색, 카테고리, 신뢰도, 수요 추세, 품질 경고와 사용자 정렬을 초기 상태로 되돌립니다. 계획 조건과 저장된 열 설정은 초기화하지 않습니다.
  • CSV 내보내기: 현재 필터와 정렬 결과 전체를 내려받습니다. 화면의 현재 페이지만 내보내는 기능이 아닙니다.

포트폴리오 수요 그래프

‘이 N개 SKU의 수요’ 그래프는 현재 필터에 남은 SKU들의 최근 26주 실제 판매와 향후 예측을 합산합니다. 필터를 바꾸면 그래프 대상도 함께 바뀝니다. 실선은 실제 판매, 모델 예측은 점선으로 표시되며, Spreadsheet V1 데이터가 있으면 비교선이 추가됩니다. V1의 SKU 포함 비율이 100%가 아니면 두 선의 크기를 직접 비교하면 안 됩니다. 제목을 눌러 그래프를 접거나 펼칠 수 있습니다.

예측 대상 표 읽는 법

표는 재고 현황 → 수요 → 조치 순서로 묶여 있습니다. SKU와 우선순위는 고정 열이고, 나머지 열은 열 버튼에서 표시 여부를 바꿀 수 있습니다.

SKU 상세 화면

예측 대상 표에서 SKU를 누르면 상세 화면이 열립니다. 이전·다음 버튼이나 SKU 선택 목록으로 업무 순서대로 이동할 수 있습니다.

영역확인할 내용
입고 전 품절 경고재고 소진일과 확정 입고 도착일 사이의 공백을 보여줍니다. 지금 발주로 공백을 메울 수 없는 경우에는 기존 입고를 앞당기거나 재고를 다른 곳에서 재배분해야 한다고 안내합니다.
권장 발주량미지급/선주문 수요, 판매 예상, 예측 오차 여유분을 더하고 현재 재고와 입고 예정분을 빼는 계산 과정을 줄별로 보여줍니다. 타당 범위와 서비스 수준 때문에 범위보다 높게 권장된 경우도 표시합니다.
예측 신뢰도이 SKU의 백테스트 평균 오차와 구간별 예측·실제 차이를 보여줍니다. 자체 측정값이 없으면 승격 SKU 평균 또는 세그먼트 중앙값 같은 대체 오차 기준을 표시합니다.
주간 수요 그래프실제 판매와 모델 예측의 흐름을 이어서 비교합니다. 모델이 최근 판매 속도보다 지나치게 높다고 판단된 경우 별도 경고 설명이 표시될 수 있습니다.
주별 수치접힌 영역을 열어 모델 예측과 Spreadsheet V1을 주 단위 숫자로 확인합니다. V1이 없는 주는 0이 아니라 ‘—’로 표시됩니다.
예측 검증모델이 보지 못한 과거 10주 구간에서 예측과 실제가 얼마나 달랐는지 그래프와 숫자로 보여줍니다.

예측 제외 화면 읽는 법

예측 제외 SKU는 최근 13주 실제 판매만 사용합니다. 판매 있음, 판매 없음, 리드타임 내 소진, 재고 없음 카드로 좁힐 수 있고, SKU/상품명 검색, 카테고리, 정렬, 페이지 크기와 CSV 내보내기를 사용할 수 있습니다.

열의미
13주 판매최근 13주 실제 판매 합계입니다. 예측값이 아닙니다.
주당13주 실제 판매에서 계산한 주평균 판매 속도입니다.
최근 판매가장 최근에 판매가 기록된 주입니다.
가용 / 입고예정현재 가용 재고와 확정 입고 수량입니다. ‘—’는 0이 아니라 해당 기록이 없거나 적용할 수 없음을 뜻할 수 있습니다.
재고 여유최근 판매 속도가 그대로 유지된다고 가정했을 때 재고가 버티는 일수입니다. 리드타임보다 짧으면 주황색과 경고 아이콘으로 표시됩니다.
⚠️
예측 제외 SKU에는 권장 발주량이 없습니다. 화면 누락이 아니라, 불규칙 판매에 모델 수요를 적용하지 않기 위한 의도입니다. 최근 판매, 실제 주문, MOQ, 공급 조건과 담당자 판단을 함께 사용하세요.

권장 발주량을 확정하기 전 체크리스트

  • 재고 데이터가 샘플이 아니고 최신 동기화 결과인지 확인합니다.
  • 입고 예정 수량과 ETA가 실제 확정 PO/컨테이너와 일치하는지 확인합니다.
  • MOQ, 발주 배수, 컨테이너 적재량, 공급업체 휴무와 실제 리드타임을 반영합니다.
  • 신뢰도가 낮거나 미측정인 SKU는 최근 판매, 프로모션, 계절성, 단종 계획을 별도로 검토합니다.
  • 입고 전 품절이지만 새 발주가 더 늦게 도착하는 경우, 발주량을 늘리기보다 긴급 운송·입고 앞당김·창고 간 재배분을 먼저 검토합니다.

문제가 있을 때

증상확인 사항
목록을 불러올 수 없음Forecast Server 상태와 AI_SERVICE_URL 대상 FastAPI 서비스가 실행 중인지 확인한 뒤 다시 시도합니다.
값 변경 후 계속 로딩계획 조건 변경은 서버 재계산 요청을 만듭니다. 여러 값을 빠르게 바꾸지 말고 마지막 요청이 끝날 때까지 기다립니다. 장시간 지속되면 서버 로그와 502/503/504 기록을 확인합니다.
목록과 상세 수량이 다름상세 URL의 리드타임, 발주 주기, 서비스 수준과 위험 기간이 목록에서 사용한 값과 같은지 확인합니다.
필터 결과가 없음초기화를 눌러 요약 카드와 필터를 해제합니다. 예측 대상/예측 제외 탭도 확인합니다.
재고가 0인데 ‘—’로 표시예측 제외 표에서 ‘—’는 재고 레코드 없음, 0은 레코드상 재고 없음으로 구분됩니다.
