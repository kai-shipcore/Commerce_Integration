수요 계획 (Planning Dashboard)

수요 계획 화면은 SKU별 판매·재고·입고 예정 정보를 한 표에서 비교하고, 컨테이너별 발주 수량을 계획하는 작업 화면입니다. 스프레드시트처럼 컬럼과 셀을 선택해 정렬·필터·숨김·색상·글꼴을 한 번에 적용할 수 있으며, 사용자가 바꾼 컬럼 이름·순서·너비·표시 상태와 서식은 사용자별로 저장됩니다.

ℹ️
가장 중요한 변경: 컬럼 헤더를 한 번 클릭해도 정렬되지 않습니다. 클릭은 헤더 선택이며, 정렬·필터·열 숨기기는 헤더를 마우스 오른쪽 버튼으로 클릭해 실행합니다.
▲ SKU 행, 고정 정보 컬럼, 판매·재고 지표와 컨테이너 계획 컬럼으로 구성된 수요 계획 화면

처음 사용할 때 — 5단계 빠른 시작

1

조회 범위 선택

카테고리·상품·긴급도·기준일을 선택하고 필요한 경우 SKU를 검색합니다.

2

필요한 컬럼만 표시

⊞ 컬럼 ▾에서 빠른 설정 또는 개별 체크박스를 선택한 뒤 적용을 누릅니다.

3

정렬·필터로 대상 좁히기

헤더를 오른쪽 클릭하고 정렬 또는 필터를 선택합니다. Note에 업무 상태를 기록해 상태별로 필터할 수도 있습니다.

4

수량 검토·입력

CBM, Note, ETA, Con. Qty 등 권한이 허용된 값을 편집하고 계산 결과를 확인합니다.

5

미저장 수량 저장

자동 계산 또는 직접 수정한 컨테이너 수량은 표시된 미저장 상태를 확인한 뒤 Save로 저장합니다.

① 상단 도구 모음과 조회

항목사용 방법
카테고리 / 상품 / 긴급도표시할 SKU 범위를 줄입니다. 여러 조건을 함께 사용하면 모든 조건을 만족하는 행만 표시됩니다.
SearchSKU 또는 화면이 지원하는 검색 대상 문자열을 입력합니다. 입력을 지우면 전체 결과로 돌아갑니다.
As of선택한 날짜를 기준으로 재고와 계획 데이터를 조회합니다. 오늘이 아닌 날짜를 선택했다면 분석 기준일을 먼저 확인하세요.
Sync최신 원천 데이터를 불러와 판매·재고·OOS 관련 계산을 갱신합니다.
Export / Import현재 조회 결과를 내보내거나 지원되는 운송 중 재고 파일을 가져옵니다. 가져오기 화면의 미리보기와 오류를 확인한 후 적용하세요.
환경 설정 / SKU 개수글꼴·채우기 색상 아이콘과 같은 크기의 독립된 환경 설정(⚙) 버튼이 표시되고, 그 오른쪽의 별도 영역에 현재 필터와 숨김 조건을 통과한 SKU 개수가 나타납니다. 환경 설정 팝업은 컬럼 설정 팝업과 같은 위치에서 열립니다.

② 헤더·전체 컬럼·셀 선택

선택 위치에 따라 색상과 글꼴이 적용되는 범위가 달라집니다. 선택된 대상은 파란색 계열 강조 표시와 도구 모음의 선택 헤더 n개, 전체 컬럼 n개, 선택 셀 n개 문구로 확인할 수 있습니다.

선택 대상방법결과
헤더만헤더의 제목 영역 클릭헤더만 선택합니다. 같은 헤더를 다시 클릭하면 선택이 해제됩니다. 이 상태에서 서식을 바꾸면 헤더에만 적용됩니다.
전체 컬럼개별 컬럼 헤더의 맨 위 얇은 선택 띠 클릭헤더 아래의 모든 데이터 셀을 포함한 전체 컬럼을 선택합니다. 선택 띠가 파란색으로 표시됩니다.
셀 하나데이터 셀 클릭해당 셀만 선택합니다. 일반 클릭은 기존 선택을 지우고 새 셀 하나를 선택합니다.
연속 셀첫 셀에서 마지막 셀까지 드래그사각형 범위의 셀을 선택합니다.

다중 선택 키

키 조합헤더 / 전체 컬럼셀
Ctrl + 클릭
Mac: Command + 클릭		떨어진 컬럼을 하나씩 추가하거나 선택 해제떨어진 셀을 하나씩 추가하거나 선택 해제
Shift + 클릭마지막 기준 컬럼부터 클릭한 컬럼까지 연속 선택기준 셀과 클릭한 셀 사이의 직사각형 범위 선택
Ctrl + Shift + 클릭현재 선택을 유지하면서 연속 범위 추가현재 선택을 유지하면서 직사각형 범위 추가
💡

③ 정렬·필터·열 숨기기

일반 컬럼과 컨테이너 하위 컬럼의 헤더를 오른쪽 클릭하면 컬럼 메뉴가 열립니다.

메뉴동작
오름차순 정렬 (A→Z)문자는 A→Z, 숫자와 날짜는 작은 값→큰 값 순서로 정렬합니다.
내림차순 정렬 (Z→A)문자는 Z→A, 숫자와 날짜는 큰 값→작은 값 순서로 정렬합니다.
필터값별 필터 또는 조건별 필터를 설정합니다. 선택 내용은 적용을 눌러야 반영되고, 취소하면 기존 필터가 유지됩니다.
열 숨기기해당 컬럼을 숨깁니다. 오른쪽 클릭한 컬럼이 현재 다중 선택에 포함되어 있으면 선택된 헤더·전체 컬럼·셀에 해당하는 모든 컬럼을 한 번에 숨깁니다. 컨테이너 하위 컬럼은 선택한 컨테이너에만 적용되며 다른 컨테이너의 같은 이름 컬럼은 유지됩니다.

필터 사용 예

  • 값별 필터: 검색창에서 값을 찾고 체크박스로 표시할 값만 선택합니다. (공백)도 하나의 값으로 선택할 수 있습니다.
  • 조건별 필터: 비어 있음/비어 있지 않음, 텍스트 포함·미포함·시작·끝·일치, 숫자 초과·이상·미만·이하·같음·다름·범위 내·범위 밖 조건을 사용할 수 있습니다.
  • 필터 해제: 값별 필터에서 모두 선택하거나 조건을 없음으로 바꾼 뒤 적용합니다.
↩️
숨긴 컬럼 복원: 숨긴 위치와 맞닿은 실제 헤더에 복원 화살표가 표시됩니다. 화살표에 마우스를 올리면 숨겨진 컬럼 이름을 확인할 수 있고, 클릭하면 연속으로 숨겨진 컬럼 묶음이 복원됩니다. 컨테이너별로 숨김 상태가 달라도 컬럼 설정의 컨테이너 표시 › 모두 표시를 누르고 적용하면 숨긴 컨테이너와 모든 컨테이너 하위 컬럼을 한 번에 복원합니다.

④ 컬럼 이름·순서·너비

작업방법저장
헤더 이름 변경일반 헤더 또는 상단 그룹/컨테이너 헤더를 더블클릭하고 큰 입력창에 이름을 입력합니다. Enter는 저장, Esc는 취소입니다. 빈 이름으로 저장하면 기본 이름으로 돌아갑니다.사용자별 저장
컬럼 순서 변경일반 컬럼은 개별 헤더를 원하는 위치로 드래그합니다. 컨테이너 이름이 있는 그룹 헤더를 드래그하면 Con. Qty, Rem. Qty, Open Orders, Avail Qty, Est. Sales, Back Order, Carry over, Inv. Life, EST. SOD, Plan SOD, CBM이 한 묶음으로 이동합니다.사용자별 저장
컬럼 너비 변경헤더 오른쪽 경계를 드래그합니다. 헤더·데이터 셀·요약/합계 영역이 같은 너비로 함께 변경됩니다.모든 컬럼을 사용자별 저장
컬럼 고정⊞ 컬럼 ▾의 컬럼 고정에서 고정 끝점을 선택합니다. 선택한 컬럼까지 왼쪽에 고정됩니다.사용자별 저장
너비 초기화컬럼 설정의 너비 초기화를 누르고 확인 창에서 승인합니다. Next ETA, EST. SOD, Plan SOD는 기본 글꼴 10px과 날짜가 보이도록 지정된 기본 너비로 돌아갑니다.기본값으로 갱신
↔️
컨테이너 그룹 정렬: 하위 컬럼 순서를 바꾸면 컨테이너 헤더 위의 합계도 같은 순서로 이동합니다. 컨테이너 그룹의 굵은 왼쪽 경계선은 CBM 위치에 고정되지 않고 현재 가장 왼쪽에 놓인 하위 컬럼으로 자동 이동합니다.
🔗
컨테이너 헤더: 컨테이너 이름을 더블클릭하면 사용자 지정 이름을 편집하고, 이름 옆의 외부 링크 아이콘을 클릭하면 해당 컨테이너 계획 상세 화면을 새 탭에서 엽니다.

⑤ 배경색·글꼴 서식

컬럼 설정 버튼 오른쪽, 환경 설정 버튼 왼쪽의 글꼴 서식 아이콘과 채우기 색상 아이콘은 현재 선택된 대상에 적용됩니다. 먼저 대상이 헤더인지, 전체 컬럼인지, 셀인지 확인하세요.

현재 선택채우기 색상글꼴 크기·굵기·색상
헤더선택한 헤더 배경만 변경선택한 헤더 텍스트에 적용
전체 컬럼해당 컬럼의 전체 데이터 셀 배경 변경해당 컬럼의 전체 데이터 셀 텍스트에 적용
셀선택한 셀 배경만 변경선택한 셀 텍스트에 적용
  • 팔레트의 기본색·표준색 또는 Custom color를 선택할 수 있습니다.
  • 글꼴 크기는 − / 숫자 입력 / +로 바꾸고, B로 굵기를 켜거나 끕니다. 밑줄이 있는 A 아이콘에서 글자색을 선택합니다.
  • 색상과 글꼴은 선택 직후 적용되며 사용자별로 저장됩니다.
  • 컨테이너 상단 그룹 헤더는 글꼴 크기와 굵기 변경을 지원하지 않지만 글자색은 지원합니다. 팝업에도 이 제한이 표시됩니다.
🎨
범위를 잘못 칠하지 않는 방법: 헤더 제목을 클릭하면 헤더만, 헤더 맨 위의 얇은 띠를 클릭하면 전체 컬럼, 데이터 셀을 클릭하면 셀만 바뀝니다. 팔레트 상단의 선택 대상과 개수를 마지막으로 확인하세요.

⑥ 컬럼 설정과 초기화

⊞ 컬럼 ▾에는 빠른 설정, 옵션, SKU 필터, 컬럼 고정, 컬럼 표시, 컨테이너 표시와 초기화 도구가 있습니다.

▲ 컬럼 설정 — 레이아웃, 색상 및 서식, 컬럼 표시와 컨테이너 표시를 한 화면에서 관리합니다.
영역설명
빠른 설정전체 / 핵심 / 간단히 중 하나를 선택하거나 컨테이너 하위 컬럼 전체를 켜고 끕니다.
옵션판매 0인 SKU 표시를 한 줄 옵션으로 켜거나 끕니다.
SKU 필터현재 카테고리에 존재하는 SKU 파트 값을 복수 선택합니다. 서로 다른 필터 항목은 AND 조건으로 결합됩니다.
컬럼 표시그룹 체크박스로 한 묶음을 제어하거나 그룹을 펼쳐 개별 컬럼을 선택합니다. 5/6은 전체 6개 중 5개 표시를 뜻합니다.
컨테이너 표시Base와 Shipped/Final/Draft 상태 그룹 또는 개별 컨테이너를 표시·숨김 처리합니다. 모두 표시는 숨긴 컨테이너와 컨테이너별 숨김 하위 컬럼을 함께 복원합니다.
✅
미리보기 후 확정: 팝업에서 체크하거나 값을 바꾸는 동안에는 변경 대기 개수만 표시됩니다. 실제 그리드에 반영하려면 하단의 적용을 누르세요. 취소, X, 바깥 영역 클릭으로 닫으면 초안은 폐기되고 기존 설정이 유지됩니다.

초기화 버튼

초기화 도구는 컬럼 레이아웃, 색상 및 서식, 모든 컬럼 설정 초기화로 구분됩니다. 실행 전 확인 창에서 범위를 확인하세요.

버튼초기화 범위
컬럼 너비 초기화 / 컬럼 순서 초기화사용자가 조정한 모든 컬럼 너비 또는 컬럼 배치 순서
헤더 색상 — 선택 / 전체 초기화선택한 헤더 또는 모든 헤더의 배경색
셀 색상 — 선택 / 모든 셀 초기화선택한 셀 또는 개별 셀에 지정한 모든 배경색
텍스트 색상 — 선택 / 전체 초기화선택 셀 또는 모든 셀의 사용자 지정 글자색
모든 텍스트 서식 초기화사용자가 지정한 글꼴 크기·굵기·글자색을 모두 기본값으로 복원
모든 컬럼 설정 초기화컬럼 너비·순서·헤더/셀 색상·텍스트 서식을 한 번에 기본값으로 복원합니다. 확인 후 즉시 적용되고 컬럼 설정 팝업이 자동으로 닫힙니다.

⑦ Note와 셀 편집

Note — SKU별 업무 태그와 메모

Note는 CBM 오른쪽에 있으며, 사용자가 자유롭게 상태나 메모를 기록하는 컬럼입니다. 예를 들어 Checked, Hold, Recheck를 입력한 뒤 Note 헤더의 값별 필터에서 Checked만 선택할 수 있습니다.

동작방법
입력Note 셀을 편집하고 내용을 입력합니다. 여러 줄을 입력할 때는 Shift + Enter, 저장할 때는 Enter 또는 셀 바깥 클릭을 사용합니다.
저장SKU 기준으로 저장되는 전체 공유 메모입니다. 다른 사용자도 같은 내용을 보고, 다른 사용자가 수정하면 그 내용으로 덮어써집니다. 저장 중에는 페이지 이동이나 새로고침을 피하세요.
필터Note 헤더 오른쪽 클릭 → 필터 → 값별 필터 또는 텍스트 포함 조건을 사용합니다.
서식Note도 다른 일반 셀처럼 글꼴 크기·굵기·글자색·배경색을 지원합니다.

기타 편집 가능한 값

값편집 시 동작
CBM셀의 큰 입력창에서 단위 CBM을 수정합니다. 저장되면 관련 컨테이너 CBM 계산에도 반영됩니다.
Con. Qty컨테이너 발주 수량 입력창에서 값을 입력합니다. 아무 값도 입력하지 않고 바깥으로 이동하거나 Enter를 누르면 0 입력과 동일하게 처리됩니다. Enter는 저장 후 같은 컬럼의 다음 행을 바로 편집하며, ↑/↓는 이전·다음 행, ←/→는 같은 행의 이전·다음 편집 가능한 Con. Qty 컬럼으로 이동합니다. 여러 Con. Qty 셀을 드래그해 선택한 뒤 Delete 또는 Backspace를 누르면 선택한 수량이 0으로 저장됩니다. 변경 후 연속 재고·품절예상일 계산이 갱신됩니다.
ETA권한이 있는 사용자는 컨테이너 헤더의 ETA를 수정할 수 있습니다. ETA 변경은 예상 판매량·Inv. Life·EST. SOD·Plan SOD에 영향을 줄 수 있습니다.
🔒
편집 권한이 없는 사용자는 데이터를 조회·정렬·필터할 수 있지만 CBM, Note, ETA, Con. Qty 및 저장 작업은 제한될 수 있습니다.

⑧ 컨테이너 계획과 자동 계산

각 컨테이너에는 Con. Qty, 잔여 재고, 오픈 오더, 가용 수량, 예상 판매, 백오더, 이월 수량, Inv. Life, EST. SOD, Plan SOD, CBM 등 계획용 하위 컬럼이 표시됩니다. 일부는 입력값이고 나머지는 앞 컨테이너와 ETA를 이어 계산한 결과입니다.

기능설명
고정 목표 계산 📅헤더의 목표 일수(기본 90일)를 사용해 SKU별 Con. Qty 초안을 계산합니다.
구간별 목표 계산 📊일판매량 구간별 목표 일수를 설정해 판매 속도가 다른 SKU에 서로 다른 재고 일수를 적용합니다.
미리보기자동 계산 결과는 즉시 그리드에 보이지만 저장 전 초안입니다. 수량·총 CBM·용량 초과 여부를 검토합니다.
Save / ResetSave는 미저장 수량을 확정하고, Reset은 저장된 마지막 값으로 되돌립니다. Reset 실행 전 확인 창이 표시됩니다.
컨테이너 상세컨테이너 헤더의 바로가기 동작을 사용하면 해당 컨테이너 계획 상세 화면을 새 탭에서 확인할 수 있습니다.

⑨ 주요 컬럼 읽는 법

컬럼의미
West / East / Transit / Total서부 가용재고, 동부 가용재고, 운송 중 재고와 전체 재고입니다. Total은 서부 + 동부 + 운송 중 기준입니다.
W/E/Total Avg지역 또는 전체 일평균 판매량입니다. Previous, Actual, Current 값은 이전 기준·실측·현재 적용값을 구분합니다.
Next ETA다음 입고 예정일입니다. 기본 글꼴 10px과 확장된 기본 너비를 사용해 날짜가 잘리지 않도록 설정되어 있습니다.
S.O.D / EST. SOD / Plan SOD재고 소진 예상일입니다. 일반 S.O.D는 현재 재고 기준, EST. SOD와 Plan SOD는 컨테이너 흐름과 계획 수량을 반영한 날짜입니다.
Inv. Life해당 단계 재고가 예상 판매 속도로 유지되는 일수입니다.
Back Order / Carry over충족하지 못한 수요와 다음 단계로 이월되는 재고 또는 부족분을 나타냅니다.

⑩ 사용자별 저장과 문제 해결

사용자별 유지되는 항목설명
컬럼 구성표시/숨김, 컨테이너 표시, 고정 끝점, 순서, 너비
이름과 서식사용자 지정 헤더 이름, 헤더/컬럼/셀 배경색, 글꼴 크기·굵기·글자색
👥
업무 메모(Note)는 사용자별이 아닙니다: SKU 기준으로 저장되는 전체 공유 메모라, 모든 사용자가 같은 내용을 보고 마지막으로 수정한 내용이 남습니다.
  • 설정이 반영되지 않음: 컬럼 설정 팝업 하단의 적용을 눌렀는지 확인합니다.
  • 정렬되지 않음: 헤더 일반 클릭은 선택입니다. 오른쪽 클릭 메뉴에서 정렬을 선택합니다.
  • 색상이 예상보다 넓게 적용됨: 팔레트 상단 대상이 헤더·전체 컬럼·셀 중 무엇인지 확인하고 필요한 초기화를 실행합니다.
  • 날짜가 …으로 보임: 헤더 경계를 넓히거나 너비 초기화로 권장 기본 너비를 복원합니다.
  • Note 또는 수량이 저장되지 않음: 편집 권한, 네트워크 연결, 저장 완료 여부를 확인한 뒤 새로고침합니다.

⑪ Planning Settings

상단의 독립된 환경 설정(⚙) 버튼에서는 시즌 지수, 판매 기간별 가중치와 OOS 손실수요 마켓 비중을 조정합니다. 팝업은 컬럼 설정과 같은 위치에서 열립니다. 값을 편집하는 동안에는 초안이며, 적용 및 동기화를 눌러야 저장과 재계산이 실행됩니다.

▲ 환경 설정 — 컬럼 설정 버튼과 같은 위치에서 열리며 시즌 지수와 판매·OOS 가중치를 관리합니다.
설정용도
시즌 지수월별 판매 배수를 설정해 ETA 월의 예상 판매량과 재고 소진 계산에 반영합니다.
판매 비중 기간별 가중치90/60/30/15/7일과 Pre 구간의 비중을 설정합니다. 합계가 100%인지 확인하세요.
OOS 손실수요 마켓 비중카테고리별 Amazon/eBay/Walmart 기대수요 비중을 자동 계산하거나 수동 지정합니다.
기본값 복원복원 버튼을 누르면 확인 절차를 거친 후 기본값으로 되돌립니다. 적용 버튼을 누르기 전에는 서버 데이터가 바뀌지 않습니다.
